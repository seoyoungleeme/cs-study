# CS 면접 스터디

[fru1tworld/cs-basic](https://github.com/fru1tworld/cs-basic) 의 면접 질문 1,224개를
간격반복(SRS)으로 공부하는 정적 PWA. 아이폰 홈 화면에 추가해 앱처럼 씁니다.

- **질문**: 레포 `interview/` 의 19개 파일에서 파싱
- **모범답안 + 객관식**: 같은 레포 `docs/` 를 근거로 전 1,224문항에 사전 생성 완료(서술형 모범답안 + 4지선다 선택지)
- **채점**: 내 답을 적으면 LLM(Gemini/OpenAI)이 모범답안과 대조해 점수·빠진 개념·꼬리질문을 돌려줌. API 키는 브라우저 localStorage 에만 저장되고 서버로 가지 않음
- **진도**: localStorage. 설정 탭에서 내보내기/가져오기
- **오프라인**: 서비스워커가 앱·데이터를 캐시해서 네트워크 없이도 동작

빌드 스크립트는 `build/` (이 저장소에는 결과물만 있음).

## 아이폰 홈 화면에 추가하기

1. Safari로 위 주소를 연다(크롬 등 다른 브라우저는 "홈 화면에 추가"가 없거나 동작이 다를 수 있다)
2. 하단 공유 버튼(네모에 화살표) 탭
3. "홈 화면에 추가" 선택
4. 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 뜬다

## 사용법

### 학습 탭

- 상단에서 **서술형 / 객관식 / 섞기** 모드를 고른다. 객관식은 선택지가 준비된 문항에서만 나오고(현재 전 문항), 매번 보기 순서를 섞어서 보여준다
- 문제를 보고 머릿속으로(또는 입력창에 적어서) 답한 뒤 **답 보기**
  - 입력창에 답을 적고 **채점**을 누르면 설정한 LLM이 모범답안과 비교해 점수·빠진 개념·꼬리질문을 준다(LLM 설정 안 했으면 채점 버튼은 꺼져 있다)
- 답을 확인한 뒤 **모름 / 애매 / 앎** 중 하나로 스스로 평가하면, 그 평가에 따라 다음 복습 주기가 간격반복(SM-2 간이 버전)으로 정해진다
- 오늘 분량을 다 풀면 "오늘 할 몫은 끝났습니다"가 뜨고, **10개 더 풀기**로 추가 진행 가능

### 둘러보기 탭

- 검색창에 키워드(예: TLB, 인덱스, 합의)를 넣으면 질문 전체에서 찾아준다
- 카테고리 칩으로 필터링해서 특정 분야만 훑어볼 수 있다

### 진도 탭

- 시작한 문항 수, 장기기억(21일 이상 간격) 문항 수, 평균 채점 점수를 보여준다
- 최근 30일 학습량 히트맵과 카테고리별 진행률 표도 있다

### 설정 탭

- **하루 분량**: 새 질문 개수, 복습 상한을 정한다
- **학습 범위**: 카테고리를 끄면 그 카테고리의 새 질문이 더 안 나온다(이미 시작한 카드의 복습은 계속된다)
- **LLM 채점**:
  1. 제공자에서 Gemini(무료 티어) / OpenAI / 직접 입력(Ollama 등 OpenAI 호환 엔드포인트) 중 선택
  2. Gemini를 쓰려면 [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 API 키를 발급받아 붙여넣는다
  3. **연결 테스트**로 키가 동작하는지 바로 확인 가능
  4. 키는 이 기기의 localStorage에만 저장되고 서버로 전송되지 않는다. 그래도 결제 한도를 걸어둔 전용 키를 쓰는 걸 권장
- **데이터**: 진도를 JSON으로 내보내기/가져오기 할 수 있어 기기를 옮기거나 백업할 때 쓴다. 진도 전체 삭제도 여기서

### 오프라인

한 번 접속하면 서비스워커가 앱과 전 문항 데이터를 캐시한다. 이후로는 비행기 모드에서도 학습 탭·둘러보기·진도·설정이 전부 동작한다(LLM 채점만 네트워크가 필요하다).
